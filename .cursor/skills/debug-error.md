Debugging workflow:

1. Reproduce the issue.
2. Analyze stack trace and logs.
3. Identify the real root cause.
4. Avoid guessing.
5. Suggest the smallest safe fix.
6. Explain why the issue happened.
7. Add regression tests when appropriate.
8. Preserve tenant isolation and existing architecture.

Important:
- Do not rewrite unrelated code.
- Prefer minimal production-safe fixes.
